# Cursor Zone

Neon mouse cursors for Windows. Pick a cursor, press Apply, done.

*Powered by **ALFAx***

## Download
Go to **Releases** (right side) and download `CursorZone_Setup.exe`.

If Windows shows "Windows protected your PC", click **More info** then **Run anyway**.
The app is not code-signed yet, which is why Windows asks.

## Features
- 36 neon cursors
- Choose size (32 / 48 / 64 px)
- Reset to Windows default any time
- No internet, no accounts, no data collected
